Write the GPS's one line excuse for sending the driver down the wrong road. The funniest line wins.

## Run it

```sh
node --experimental-strip-types main.ts
```

The program writes a single funny line to `$OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
